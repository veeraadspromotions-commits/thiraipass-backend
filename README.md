# 🎟️ ThiraiPass (திரைபாஸ்)

நவீன திரைப்பட மற்றும் கலை நிகழ்ச்சிகளுக்கான டிக்கெட் முன்பதிவு செயலி (BookMyShow மாற்று).

## அம்சங்கள்
- திரைப்படங்கள் மற்றும் சென்னை திரையரங்குகள் பட்டியல்
- நேரலை இருக்கை தேர்வு (Real-time Seat Selection)
- இரட்டைப் பதிவைத் தடுக்கும் இருக்கை பூட்டுதல் (Seat Locking)
- உடனடி டிஜிட்டல் டிக்கெட் & QR Code தலைமுறை
